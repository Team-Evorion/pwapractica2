## 📌 Descripción del Proyecto

Este repositorio contiene el desarrollo de la **Clase Práctica 2 de Programación Web Avanzada**, realizada por estudiantes de la carrera de Ingeniería en Sistemas Inteligentes de la Universidad Bolivariana del Ecuador.

El proyecto presenta una página web dedicada al **entretenimiento cinematográfico**, compuesta por una portada principal y un carrusel interactivo que permite explorar diferentes películas y series.

Para su desarrollo se utilizaron **HTML5, CSS3 y JavaScript**, manteniendo cada tecnología organizada en archivos y carpetas independientes.

## ✨ Funcionalidades

- Portada principal de presentación.
- Navegación entre las secciones del sitio.
- Carrusel interactivo de películas y series.
- Botones para avanzar y retroceder por el contenido.
- Indicadores visuales de navegación.
- Diseño adaptable para computadoras, tabletas y dispositivos móviles.
- Organización independiente de los archivos HTML, CSS y JavaScript.
- Publicación del proyecto mediante GitHub Pages.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura y contenido de las páginas.
- **CSS3:** Diseño visual, colores, distribución y animaciones.
- **JavaScript:** Funcionamiento e interactividad del carrusel.
- **Git:** Control de versiones del proyecto.
- **GitHub:** Almacenamiento y trabajo colaborativo.
- **GitHub Pages:** Publicación de la página web.

***

## 🚀 Ejecución del Proyecto

### Opción 1: Desde GitHub Pages

1. Acceder al enlace de la página web.
2. Explorar la portada principal.
3. Seleccionar la opción para visualizar el carrusel.
4. Navegar entre las diferentes películas y series.

### Opción 2: Desde una computadora

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador.
4. Navegar por el contenido cinematográfico.

**No es necesario instalar dependencias adicionales.**
